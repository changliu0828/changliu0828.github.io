# Setup
```bash
brew install rbenv

rbenv init

$ ruby --version
ruby 3.4.4

gem install jekyll

$ jekyll -h
jekyll 4.4.1 -- Jekyll is a blog-aware, static site generator in Ruby
```

## Preview on local
```bash
bundle exec jekyll serve
```
